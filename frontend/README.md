# AegisAI Frontend

React + TypeScript + Vite + Tailwind + Recharts dashboard.

This directory will be scaffolded in **Phase 5**. Planned bootstrap:

```bash
npm create vite@latest . -- --template react-ts
npm install
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
npm install recharts
```

The dashboard visualizes firewall decisions, trust scores, policy hits, and
agent telemetry served by the backend API.
